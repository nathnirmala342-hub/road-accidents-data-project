# Road Accident Analysis - India

An exploratory data analysis (EDA) project on road accidents: when and why they happen, which road and vehicle types are most dangerous, and how states compare. Includes an analysis script that saves charts and an interactive Streamlit dashboard.

> **Important:** the bundled `data/accidents.csv` is **synthetic sample data** generated by `make_sample_data.py` so the project runs out of the box. It only imitates broad patterns. **Do not present its numbers as real findings.** Swap in real data (below) before putting results on a resume or portfolio.

## Project structure

```
road-accidents-india/
├── data/accidents.csv       # sample data (replace with real data)
├── make_sample_data.py      # generates the synthetic sample
├── analysis.py              # cleaning + 6 charts + printed key findings
├── app.py                   # Streamlit dashboard
├── requirements.txt
└── README.md
```

## Run it

```bash
pip install -r requirements.txt
python analysis.py          # saves charts into outputs/ and prints findings
streamlit run app.py        # interactive dashboard
```

## Use real data (do this next)

Good sources:
- **data.gov.in** (Open Government Data Platform India): search "road accidents".
- **Ministry of Road Transport and Highways (MoRTH)** annual "Road Accidents in India" reports.
- Kaggle road accident datasets for India.

Real data is usually aggregated by state and year (not one row per accident), so you may need to adapt the charts. The analysis script expects these columns: `Date, Hour, State, Road_Type, Vehicle_Type, Cause, Weather, Killed, Injured`. Rename or reshape your data to match, or edit `analysis.py` to fit what you have.

## What the analysis covers

1. Accidents by hour of day
2. Main causes
3. Deaths by state
4. Fatality rate by road type and vehicle type
5. Monthly trend (including the 2020 lockdown period)
6. Weekday x hour heatmap
